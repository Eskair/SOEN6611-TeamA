## Problem 4 (a) — Keyoumu Aisikeer [implementation]

- Implement Montréal Interac ABM in Java from the D1 use-case model.
- GUI with Java Swing; OOP; helpful exception messages; internal and external reuse.
- Source must compile with `javac` without depending on one IDE.
- Stay inside D1 scope: CAD only, EN/FR, chip-and-PIN, simulator (no live Interac, no USD, no crypto, no bill-pay).

## Problem 4 (b) and Problem 5 — Shubo Debnath [tests + SLOC]

- Test the product with representative data (success and exception paths).
- State the SLOC counting scheme.
- Report Physical SLOC and Logical SLOC on production source only (exclude tests).

## Problem 6 — Himanshu Banwal [readability]

- Select one authoritative readability metric and say why.
- Measure the iBank source with that metric.
- Comment on qualitative conclusions versus the metric’s published thresholds.
